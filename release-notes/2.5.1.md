## 2.5.1

This is the first release under the fork's new name, **Export Image (Fork)**, maintained by [miuarc](https://github.com/mistn).

The plugin keeps the upstream id `obsidian-export-image`, so existing settings, hotkeys and BRAT installations continue to work. The release assets now also include `LICENSE` and `main.js.LEGAL.txt` for MIT compliance.

### Changed

- Rebranded the plugin as **Export Image (Fork)**.
- Updated the manifest author to `miuarc` and the author URL to `https://github.com/mistn`.
- Removed the original author's sponsor link from the manifest. All original credit remains in the README and LICENSE.
- Added release notes automation for future releases.
- Included the license notices in release assets and in the packaged zip.

### Highlights from 2.5.0

- Choose PNG, transparent PNG, JPG, WEBP or PDF directly in the export preview. ([#92](https://github.com/zhouhua/obsidian-export-image/issues/92))
- Customize author avatar size, author name font size and author area padding.
- Optionally override the body font size.
- File-menu and selection exports use the requested content, and reading-mode exports no longer produce empty images. ([#4](https://github.com/zhouhua/obsidian-export-image/issues/4))
- Folder exports keep theme styles and custom CSS, embedded notes no longer show scrollbars, and long code blocks are not clipped. ([#125](https://github.com/zhouhua/obsidian-export-image/issues/125), [#65](https://github.com/zhouhua/obsidian-export-image/issues/65), [#95](https://github.com/zhouhua/obsidian-export-image/issues/95))
- Callout icons, checked task list items and async code blocks are exported correctly. ([#117](https://github.com/zhouhua/obsidian-export-image/issues/117), [#49](https://github.com/zhouhua/obsidian-export-image/issues/49), [#127](https://github.com/zhouhua/obsidian-export-image/issues/127))
- Fixed the disabled Copy button, empty image responses, PDF encoding and `split mode = none`. ([#56](https://github.com/zhouhua/obsidian-export-image/issues/56), [#41](https://github.com/zhouhua/obsidian-export-image/issues/41))
- Updated jsPDF, lodash, jszip, esbuild and React; the production dependency audit is clean.

See [the 2.5.0 release notes](./2.5.0.md) and [CHANGELOG.md](../CHANGELOG.md) for the complete list with upstream issue links.
